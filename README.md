WE Folder First 33 — 让 Wallpaper Engine 的库窗口先显示文件夹

作用
  Wallpaper Engine 点托盘图标打开库窗口时，会先铺满所有壁纸的缩略图。
  装了这个之后，打开时一张缩略图都不加载，直接给你「我的文件夹」（你在 WPE 里建的文件夹，
  多层嵌套也支持）和「按标签分类（会先退出文件夹）」：
    · 屏幕上还有一个圆钮：左键点一下＝收起/展开文件夹面板；按住可以拖到任意位置（位置会记住）；
    · 点文件夹卡片进入子文件夹；面包屑可逐级返回；
    · 点「按标签分类（会先退出文件夹）」里的标签＝只看这个标签的壁纸；
    · 标签后面的数字按你当前的壁纸库实时统计；某个标签一个壁纸都没有时不会出现。
    · 想回到原版那种一整片壁纸，点「全部壁纸」卡片。
  更详细的图文说明见同目录「安装教程.html」（双击用浏览器打开）。

安装（1 分钟）
  1. 解压，双击「安装.cmd」。
  2. 它会自动找 Steam 里的 Wallpaper Engine，找不到会让你手输安装目录。
  3. 装完关掉 Wallpaper Engine 库窗口，托盘图标退出，再点托盘图标打开一次即可生效。
     如果看不到变化：右键托盘图标 → 退出 Wallpaper Engine，重新打开，再点托盘图标。
     装在 C:\Program Files (x86)\Steam 时可能需要右键「以管理员身份运行」。

Steam 更新之后（重要）
  Steam 更新 Wallpaper Engine 或「验证文件完整性」时，会覆盖 ui\dist，
  注入会被冲掉，界面回到原版。这时不用卸载，双击「修复.cmd」即可：
    · 它先自检（注入标记 / 脚本 / 备份三项），正常就只打印「一切正常」不动文件；
    · 检测到失效才重装，并顺手把 index.html.orig 备份刷新成 Steam 更新后的新版。
  重启电脑不会让它失效，只有 Steam 更新或重装 WPE 才会。

可选：让它自动恢复（开机自检）
  双击「自动修复.cmd」开启。它做两件事：
    · 把 repair.ps1 / 安装.ps1 / wefolderfirst.js 复制到 %LOCALAPPDATA%\WEFolderFirst；
    · 在 HKCU\...\Run 写一条启动项（wscript 启动，不弹黑窗，不需要管理员）。
  之后每次登录会静默自检一次（正常时 <1 秒、什么都不改）；只有注入被 Steam 冲掉才会自动重装。
  取消：双击「取消自动修复.cmd」（会删启动项和那个目录）。卸载时也会自动取消。
  只影响当前 Windows 账户，不写系统计划任务。

卸载
  双击「卸载.cmd」。会还原 index.html、删掉脚本和数据目录。
  如果 Steam 刚更新过（当前 index.html 不含注入），它会跳过还原，
  避免用旧备份盖掉 Steam 刚写的新版文件。

打开设置（悬浮球）
  右键点悬浮球，或者按住它不动约 0.65 秒。左键单击只是开/关文件夹面板；
  双击不会打开设置（21 版修的就是左键误触）。再按一次右键、或者按 Esc，设置面板就收起来。
  设置里有一行「打开时」，可以选下次打开库窗口的开场：
    · 文件夹面板（默认）：一打开就看到文件夹和标签，一张缩略图都不加载；
    · 只显示球：一打开只有一个悬浮球，点它才展开面板。
  选择会记在这台电脑上，点了立即生效，下次打开也照这个来。

文件夹后面为什么写着「N 个壁纸」
  这个数字只统计库里还存在的壁纸：已经卸载、或者文件失效的壁纸不会算进去。
  所以不会出现「写着 10 个，点进去却是空的」这种情况（30 版修的）。
  有子文件夹的会把子文件夹里的也一起算上，卡片上会写「N 个子文件夹 · M 个壁纸」。
悬浮球为什么放不到窗口最上面
  Wallpaper Engine 窗口顶部那条标题栏属于系统拖动区，鼠标按上去会被拿走去拖窗口，
  网页根本收不到点击。所以悬浮球不允许贴在最上面：拖过去会自动往下让开一点，
  并提示「顶边是窗口自己的拖动条」。这样就不会出现「拖不动、也点不开设置」。

调整悬浮球的大小和形状
  设置面板里有：
    · 「大小」滑杆：24–96 px，拖动即时生效，位置会记住；
    · 「形状」两个按钮：圆形 / 圆角矩形（圆角矩形是宽 1.6 倍、四角带弧度的长方形）。
  想让所有人统一：编辑 <Wallpaper Engine>\ui\dist\scripts\wefp\config.json 里的
  fabSize（数字）和 fabShape（"circle" 或 "rect"）。

换悬浮球的图标
  设置面板 →「选择图片」，挑一张图即可；
  图片会缩到 128×128 只存在本机，不会上传，也不会改安装目录。
  默认图标就是最初始的 📁；选过自己的图之后会记住，想变回 📁 就右键悬浮球→恢复默认。
  恢复默认：设置面板 →「恢复默认」，回到 📁 表情（清掉你选的图）。
